## 📋 Step-by-Step Instructions

### Step 1: Install Client Dependencies (2-3 minutes)

Open PowerShell and run:

```powershell
cd "c:\Users\SWANTIN\Desktop\BUSSINESS MANAGEMENT SYSTEM\client"
npm install
```

**Wait for it to finish** (you'll see "added X packages")

---

### Step 2: Start the Frontend

After installation completes, run:

```powershell
npm run dev
```

You'll see:
```

```

---

### Step 3: Open Your Browser

Go to: **http://localhost:5173**

```powershell

# Run backend (after setting up .env)

# Or run both together (from root folder)
npm run dev
```
